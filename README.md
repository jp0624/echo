# Echo

A compact React brand presentation featuring a custom SVG wordmark.

[Live demo](https://www.echobite.ca/)

## Local development

Run these commands from the repository root:

```sh
npm install
npm run dev
```

Available scripts:

- `npm run build`: `tsc && vite build`.
- `npm run lint`: `eslint . --ext ts,tsx --report-unused-disable-directives --max-warnings 0`.
- `npm run preview`: `vite preview`.

## Main dependencies

`react`. See `package.json` for the full dependency list and versions.
